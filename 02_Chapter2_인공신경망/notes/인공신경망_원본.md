
노드와 엣지로 구성되어 있다.
웨이트(중요도) 곱하고 바이어스(민감도)와 함께 더하는, 액티베이션
여러가지 액티베이션이 존재, 여기서 나온 것은 Unit Step Function
주어진 입력에 대해 원하는 출력이 나오도록 weight와 bias를 설정해줘야한다.
그런데, AI가 weight와 bias를 학습을 통해 알아낸다.

ANN

각 노드는 각각 다른 역할을 부여받는다.

* input Layer
* output Layer
* Hidden Layer

노드끼리 연결한 층을 Fully-Connected Layer라고 한다.
모든 레이어가 FC Layer인 신경망을 MLP라고 한다.

## 인공신경망은 함수다.

* Linear Activation을 만들어보자. [ y = ax + b ]
* Linear Regression (선형 회귀)
		입력과 출력간의 관계를 알아내기 위함.
		처음보는 입력에서도 적절한 출력값을 냄.
		조회수로 수익을 예측하는 AI 모델을 만들어보자.
		다른 유튜버의 영상의 조회수를 보고도 수익을 예측하는 모델을 만들어보자.

		분류는? 사진만 보고 어떤 클래스에 속하는지 예측하는 AI 모델이다.
		결국 분류와 회귀는 같다.
	우리는 최적의 웨이트(a)와 바이어스(b)를 선택하기 위해서 선택한 웨이트(a)와 바이어스(b)가 좋고 나쁨을 판단할 수 있어야한다. -> Loss를 최소화 하는 a와 b가 최적의 a, b
	loss 라는 것은 내가 풀고 싶은 문제에 맞게 잘 정의하는 것이다. (무엇을 줄여야 좋을까?)
	AI와 실제 수익과의 차이에 대해 error를 정의해보자.
a와 b를 일일이 바꿔가며 Loss의 그래프를 그려보고 최소의 Loss값을 가지게하는 a와 b의 자표를 찾는다.
하지만 이러한 과정은 시간이 너무 오래 소요된다는 치명적인 단점이 존재한다.
