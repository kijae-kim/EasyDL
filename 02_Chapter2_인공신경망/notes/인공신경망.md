## 1️⃣ 인공신경망의 기본 구조

### 1.1 구성 요소

인공신경망은 **노드(Node)**와 **엣지(Edge)**로 구성됩니다.

#### 노드 (Node / Neuron)
- 생물학적 뉴런을 모방한 연산 단위
- 입력을 받아 가중합과 활성화 함수를 거쳐 출력 생성

#### 엣지 (Edge / Connection)
- 노드 간의 연결
- 각 엣지는 **가중치(Weight, w)**를 가짐
- 가중치 = 해당 입력의 중요도

### 1.2 노드의 연산 과정

하나의 노드는 다음 과정을 수행합니다:

$$
z = \sum_{i=1}^{n} w_i x_i + b
$$

$$
y = f(z)
$$

**수식 설명**:
- $x_i$ : 입력값 (input)
- $w_i$ : 가중치 (weight) - **입력의 중요도**
- $b$ : 바이어스 (bias) - **민감도 조절**
- $z$ : 가중합 (weighted sum)
- $f$ : 활성화 함수 (activation function)
- $y$ : 출력값 (output)

**구체적 예시**:

입력이 2개인 경우:
$$
z = w_1 x_1 + w_2 x_2 + b
$$

예를 들어, $x_1 = 2, x_2 = 3, w_1 = 0.5, w_2 = 0.8, b = 1$ 이면:
$$
z = 0.5 \times 2 + 0.8 \times 3 + 1 = 1 + 2.4 + 1 = 4.4
$$

### 1.3 활성화 함수 (Activation Function)

**Unit Step Function** (계단 함수):
$$
f(z) = \begin{cases}
1 & \text{if } z \geq 0 \\
0 & \text{if } z < 0
\end{cases}
$$

이 외에도 다양한 활성화 함수가 존재합니다:
- **Sigmoid**: $\sigma(z) = \frac{1}{1 + e^{-z}}$
- **ReLU**: $f(z) = \max(0, z)$
- **Tanh**: $f(z) = \tanh(z)$

## 2️⃣ 인공신경망의 레이어 구조

### 2.1 레이어의 종류

**Input Layer (입력층)**:
- 데이터를 받아들이는 층
- 입력 특징(feature)의 개수 = 노드 개수

**Hidden Layer (은닉층)**:
- 입력과 출력 사이의 중간 층
- 복잡한 패턴을 학습
- 깊은 신경망 = 여러 개의 은닉층

**Output Layer (출력층)**:
- 최종 예측값을 출력하는 층
- 분류 문제: 클래스 개수 = 노드 개수
- 회귀 문제: 1개의 노드

### 2.2 Fully Connected Layer (완전 연결층)

**정의**: 이전 층의 모든 노드가 다음 층의 모든 노드와 연결된 층

**표기**: FC Layer, Dense Layer

**MLP (Multi-Layer Perceptron)**:
- 모든 레이어가 FC Layer인 신경망
- 가장 기본적인 인공신경망 구조

**예시 구조**:
```
Input(3) → Hidden(4) → Hidden(2) → Output(1)
```
- 입력: 3개의 특징
- 첫 번째 은닉층: 4개 노드
- 두 번째 은닉층: 2개 노드
- 출력: 1개 값 (회귀 문제)

## 3️⃣ 인공신경망은 함수다

### 3.1 함수적 관점

인공신경망은 **입력($x$)을 출력($y$)으로 매핑하는 함수**입니다:

$$
y = f_{\theta}(x)
$$

여기서 $\theta = \{w_1, w_2, ..., w_n, b_1, b_2, ..., b_m\}$ (모든 가중치와 바이어스)

**핵심 아이디어**:
> AI 학습 = 최적의 함수 찾기 = 최적의 파라미터($\theta$) 찾기

### 3.2 선형 함수 (Linear Function)

가장 간단한 형태: **선형 함수**

$$
y = ax + b
$$

- $a$ : 기울기 (가중치, weight)
- $b$ : y절편 (바이어스, bias)
- $x$ : 입력
- $y$ : 출력

**의미**:
- $a$가 크면 → 입력 변화에 출력이 민감하게 반응
- $b$가 크면 → 전체적인 출력값이 상승

### 3.3 선형 회귀 (Linear Regression)

**목표**: 입력($x$)과 출력($y$) 간의 **선형 관계**를 학습

$$
\hat{y} = wx + b
$$

- $\hat{y}$ : 예측값 (predicted value)
- $y$ : 실제값 (actual value)

**실전 예시**:
- 입력($x$): YouTube 조회수
- 출력($y$): 예상 수익
- 학습 후: 처음 보는 조회수에서도 수익을 예측 가능

**확장**:
- 회귀(Regression): 연속적인 값 예측 (예: 가격, 온도)
- 분류(Classification): 이산적인 클래스 예측 (예: 고양이/개)

> **중요**: 회귀와 분류는 근본적으로 같은 원리! 출력 형태만 다를 뿐

## 4️⃣ Loss 함수 (손실 함수)

### 4.1 Loss 함수란?

**정의**: 예측값($\hat{y}$)과 실제값($y$) 사이의 **오차를 측정**하는 함수

$$
\text{Loss} = L(y, \hat{y})
$$

**목적**:
- Loss가 작을수록 모델이 정확함
- AI 학습 = Loss를 최소화하는 $w$와 $b$ 찾기

### 4.2 MSE (Mean Squared Error)

**가장 대표적인 회귀 문제 Loss 함수**:

$$
\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

**수식 설명**:
- $n$ : 데이터 개수
- $y_i$ : $i$번째 실제값
- $\hat{y}_i$ : $i$번째 예측값
- $(y_i - \hat{y}_i)$ : 오차 (error)
- 제곱하는 이유: 음수 오차를 양수로, 큰 오차에 더 큰 패널티

**구체적 예시**:

데이터가 3개일 때:
| 실제값($y$) | 예측값($\hat{y}$) | 오차 | 제곱 오차 |
|-------------|-------------------|------|-----------|
| 100 | 95 | -5 | 25 |
| 200 | 210 | 10 | 100 |
| 150 | 145 | -5 | 25 |

$$
\text{MSE} = \frac{25 + 100 + 25}{3} = \frac{150}{3} = 50
$$

### 4.3 Loss를 최소화하는 방법

**문제 정의**:
$$
\min_{w, b} \text{Loss}(w, b)
$$

최적의 $w$와 $b$를 찾아야 합니다.

**방법 1: 완전 탐색 (Brute Force)**
- $w$와 $b$를 일일이 바꿔가며 Loss 계산
- Loss가 최소인 조합 선택
- **단점**: 시간이 너무 오래 걸림 (비현실적)

**방법 2: Gradient Descent (경사 하강법)** ✅
- 미분을 활용한 효율적인 최적화 방법
- 현재 위치에서 Loss가 감소하는 방향으로 이동
- **다음 Chapter에서 자세히 학습!**

## 5️⃣ Gradient Descent 기초 개념

### 5.1 기본 아이디어

**비유**: 안개 낀 산에서 가장 낮은 곳을 찾기
1. 현재 위치에서 주변을 살핀다
2. 가장 가파르게 내려가는 방향을 찾는다
3. 그 방향으로 한 걸음 이동한다
4. 반복

**수학적 표현**:

$$
w_{\text{new}} = w_{\text{old}} - \alpha \frac{\partial L}{\partial w}
$$

$$
b_{\text{new}} = b_{\text{old}} - \alpha \frac{\partial L}{\partial b}
$$

**수식 설명**:
- $\alpha$ : 학습률 (learning rate) - 한 번에 얼마나 이동할지
- $\frac{\partial L}{\partial w}$ : Loss를 $w$로 편미분 (기울기, gradient)
- 기울기가 양수면 → $w$ 감소 방향으로 이동
- 기울기가 음수면 → $w$ 증가 방향으로 이동

### 5.2 편미분 예시

선형 회귀에서 $\hat{y} = wx + b$이고 Loss가 MSE일 때:

$$
L = \frac{1}{n} \sum_{i=1}^{n} (y_i - (wx_i + b))^2
$$

**$w$에 대한 편미분**:
$$
\frac{\partial L}{\partial w} = -\frac{2}{n} \sum_{i=1}^{n} x_i(y_i - (wx_i + b))
$$

**$b$에 대한 편미분**:
$$
\frac{\partial L}{\partial b} = -\frac{2}{n} \sum_{i=1}^{n} (y_i - (wx_i + b))
$$

**의미**:
- 편미분 값이 크면 → 해당 방향으로 Loss가 급격히 변화
- 편미분 값이 0이면 → 최적점 (local minimum)

### 5.3 학습 과정 요약

```python
# 초기화
w = random_value
b = random_value

# 반복 학습
for epoch in range(num_epochs):
    # 1. 예측
    y_pred = w * x + b

    # 2. Loss 계산
    loss = mean_squared_error(y, y_pred)

    # 3. Gradient 계산
    dL_dw = compute_gradient_w(x, y, y_pred)
    dL_db = compute_gradient_b(y, y_pred)

    # 4. 파라미터 업데이트
    w = w - learning_rate * dL_dw
    b = b - learning_rate * dL_db

    # 5. 수렴 확인
    if loss < threshold:
        break
```

## 6️⃣ 핵심 정리

### 📌 인공신경망 구조
1. **노드와 엣지**: 가중치로 연결된 연산 단위
2. **레이어**: Input → Hidden → Output
3. **Fully Connected**: 모든 노드가 연결된 층
4. **MLP**: 모든 층이 FC인 가장 기본적인 신경망

### 📌 함수적 관점
1. **신경망 = 함수**: $y = f_\theta(x)$
2. **선형 함수**: $y = ax + b$ (가장 간단한 형태)
3. **선형 회귀**: 입력-출력 관계를 선형 함수로 학습
4. **회귀 vs 분류**: 근본 원리는 같음, 출력 형태만 다름

### 📌 Loss와 최적화
1. **Loss 함수**: 예측값과 실제값의 오차 측정
2. **MSE**: $\frac{1}{n}\sum(y - \hat{y})^2$ (회귀 문제의 대표 Loss)
3. **최적화 목표**: Loss를 최소화하는 $w, b$ 찾기
4. **Gradient Descent**: 미분을 이용한 효율적 최적화

### 📌 Gradient Descent
1. **기본 원리**: 기울기 반대 방향으로 이동
2. **업데이트 규칙**: $w_{\text{new}} = w_{\text{old}} - \alpha \frac{\partial L}{\partial w}$
3. **학습률($\alpha$)**: 이동 크기 조절
4. **편미분**: Loss의 각 파라미터에 대한 변화율

## 7️⃣ 실습 예제

### 예제 데이터

YouTube 조회수로 수익 예측:

| 조회수 (x) | 수익 (y) |
|------------|----------|
| 1000 | 10 |
| 2000 | 18 |
| 3000 | 32 |
| 4000 | 41 |
| 5000 | 48 |

**목표**: $y = wx + b$ 형태의 선형 함수 찾기

**최적 해 (정답)**:
- 최소제곱법(Least Squares)을 사용하면:
$$
w = \frac{n\sum xy - \sum x \sum y}{n\sum x^2 - (\sum x)^2}
$$

$$
b = \frac{\sum y - w\sum x}{n}
$$

계산 결과: $w \approx 0.0095, b \approx 1.5$

**예측**:
- 조회수 6000일 때 예상 수익: $0.0095 \times 6000 + 1.5 = 58.5$

## 🤔 Q&A

### Q1: 가중치와 바이어스의 차이는?
**A**:
- **가중치($w$)**: 입력의 중요도. $w$가 크면 해당 입력이 출력에 큰 영향
- **바이어스($b$)**: 민감도 조절. 전체적인 출력값을 상하로 이동

예: $y = 2x + 10$
- 가중치 2: $x$가 1 증가하면 $y$는 2 증가
- 바이어스 10: 전체적으로 출력값이 10만큼 높아짐

### Q2: 왜 MSE는 제곱을 사용하나?
**A**:
1. **부호 제거**: 음수 오차와 양수 오차가 상쇄되는 것을 방지
2. **큰 오차 강조**: 제곱하면 큰 오차에 더 큰 패널티
3. **미분 가능**: 경사하강법 적용을 위해 미분 가능해야 함
4. **수학적 편의성**: 정규분포 가정 하에 최적 손실함수

### Q3: 왜 완전 탐색은 비현실적인가?
**A**:
- 파라미터가 2개($w, b$)만 있어도 각각 1000가지 값을 시도하면 1,000,000번 계산
- 실제 딥러닝 모델은 수백만~수십억 개의 파라미터
- 완전 탐색은 계산적으로 불가능 → Gradient Descent 필요

### Q4: 신경망은 왜 "신경망"이라고 부르나?
**A**:
- 생물학적 뉴런의 구조를 모방
- **뉴런**: 입력 신호를 받아 처리 후 출력
- **시냅스**: 뉴런 간 연결 (가중치에 해당)
- **활성화**: 특정 임계값 이상일 때 신호 전달 (활성화 함수)
