# 선형회귀와 최적화 알고리즘

---

## 경사하강법 (Gradient Descent)

### 핵심 개념

- **Gradient는 항상 가장 가파른 방향을 향한다.**
- **Learning Rate (LR)**: 그래디언트의 반대 방향으로 이동할 때 그 보폭을 조절하는 역할

### 수식

$$\theta_{t+1} = \theta_t - \alpha \cdot \nabla_\theta L(\theta_t)$$

- $\theta$: 파라미터 (가중치)
- $\alpha$: 학습률 (Learning Rate)
- $\nabla_\theta L$: 손실 함수의 그래디언트

---

## 가중치 초기화 (Weight Initialization)

### 왜 중요한가?

Initial Weight는 어떻게 설정할까?
> weight initialization

- 랜덤하게 0 근처로 값을 설정하자.

### 주요 초기화 방법

| 방법 | 수식 | 특징 |
|-----|------|------|
| **LeCun** | $\text{Var}(W) = \frac{1}{n_{in}}$ | 입력 노드 수만 고려 |
| **Xavier (Glorot)** | $\text{Var}(W) = \frac{2}{n_{in} + n_{out}}$ | Sigmoid/Tanh에 적합 |
| **Kaiming (He)** | $\text{Var}(W) = \frac{2}{n_{in}}$ | ReLU에 적합 |

### $n_{in}$과 $n_{out}$을 고려하는 이유

- **$n_{in}$이 많을 경우**: 합산되는 값의 분산이 커짐 → Activation 포화 위험
- **$n_{out}$이 많을 경우**: 역전파 시 그래디언트의 분산이 커짐 → 불안정한 학습
- **목표**: 순전파와 역전파 모두에서 안정적인 신호 전파

### 잘못된 초기화의 문제

| 초기화 | 문제점 |
|-------|-------|
| 전부 0으로 | 모든 뉴런이 동일한 그래디언트 → 대칭성 문제 (학습 불가) |
| 전부 1로 | 값이 폭발적으로 증가 → Gradient Exploding |
| 너무 작은 값 | 신호가 사라짐 → Gradient Vanishing |

---

## 경사하강법의 단점

1. **계산 속도가 너무 느리다**
   - 전체 데이터에 대해 Loss를 계산해야 함
   - 데이터가 많을수록 연산량이 $O(N)$으로 증가

2. **Local Minimum 문제**
   - Global Minimum이 아닌 Local Minimum에 갇힐 수 있음
   - 탈출 방법? → SGD, Momentum 등으로 해결

---

## SGD (Stochastic Gradient Descent)

랜덤하게 데이터를 추출해서 Loss를 계산한다.

### 특징

- 덜 신중하지만 연산이 빠르다.
- **예시**: X1 추출 → 업데이트 → X5 추출 → 업데이트 → ... [반복학습]
- 미분이 충분히 작아지면 **Local Minimum으로부터 탈출** 할 수 있다.

### 수식

$$\theta_{t+1} = \theta_t - \alpha \cdot \nabla_\theta L(\theta_t; x_i, y_i)$$

- 전체 데이터가 아닌 **단일 샘플** $(x_i, y_i)$에 대해 그래디언트 계산

### 왜 Gradient가 +방향으로 향하지 않을까?

> 하나의 데이터에 대한 Loss함수는 +를 향하는 것이 맞지만, 전체 데이터를 대상으로 봤을 때는 대각선 방향으로 향하는 것처럼 보인다.

- 개별 샘플의 그래디언트는 노이즈가 있지만, 평균적으로 전체 그래디언트 방향과 유사

---

## Mini-batch GD

SGD는 한 가지 데이터만 보고 Loss와 GD를 결정한다.
**Mini-batch GD**는 데이터를 그룹으로 정해 더해서 Loss를 구한다.

### 수식

$$\theta_{t+1} = \theta_t - \alpha \cdot \frac{1}{|B|} \sum_{i \in B} \nabla_\theta L(\theta_t; x_i, y_i)$$

- $B$: 미니배치 (일부 데이터 그룹)
- $|B|$: 배치 크기

### 장점

- **GPU 병렬처리**: SGD를 이용해도 학습 속도를 크게 향상시킬 수 있다.
- **노이즈 감소**: 단일 샘플보다 안정적인 그래디언트 추정

### 참고 논문

> "Accurate, Large Minibatch SGD: Training ImageNet in 1 Hour" - Priya Goyal 외 8인

**핵심 내용**: 무작정 Batch-Size를 키우지 말고 8k 정도로만 키우자.

1. **Linear Scaling Rule**: Learning Rate를 키워라 (배치 크기에 비례)
2. **Learning Rate Warmup**: 초기에는 작은 LR로 시작하여 점진적으로 증가

## Momentum

### 문제 인식

GD에서는 그래디언트가 항상 등고선에 수직하기 때문에 최저점을 향해 **지그재그**로 움직인다.
전체 데이터의 Loss 함수 등고선이 타원형이라면, 개별 데이터나 Mini-Batch의 등고선 또한 유사한 형태일 가능성이 높다.

### 해결책: Momentum

모멘텀은 **이전 그래디언트들을 누적**하여 현재의 이동방향을 결정한다.
물리학의 **관성** 개념과 유사하다.

### 수식

$$v_t = \gamma \cdot v_{t-1} + \alpha \cdot \nabla_\theta L$$
$$\theta_t = \theta_{t-1} - v_t$$

- $v_t$: 속도 (velocity)
- $\gamma$: 모멘텀 계수 (보통 0.9)

### 작동 원리

1. GD와 동일한 방향으로 이동
2. 현재와 이전 그래디언트를 합산하여 방향을 결정
3. 현재 그래디언트가 왼쪽을 가리켜도 직전의 오른쪽 이동 관성이 남아 왼쪽으로의 이동이 제한된다.
4. 이 과정이 반복되면서 좌우 움직임은 상쇄되지만, 전반적인 하강 방향(최저점을 향한 방향)으로의 움직임은 누적된다.
5. 결과적으로, **불필요한 좌우 진동을 줄이며** 최저점을 향해 더 빠르고 직접적으로 나아간다.

- 때로는 관성으로 인해 최저점을 약간 지나칠 수 있지만, 전체적으로 더 효율적 학습이 가능하다.
- SGD, Mini-batch GD에도 적용 가능.

## RMSProp (Root Mean Squared Propagation)

### 문제 인식

모멘텀이 이전 그래디언트를 더해서 누적했던 것과 다르게, RMSProp은 **각 파라미터에 대한 편미분 값을 제곱하여 누적**한다.

### 예시

파라미터가 $a$와 $b$ 두 개일 때, 첫 시점 이동 방향이 $[0.1, 10]$으로 계산되었다고 가정해보자.
이 경우 $b$축으로 크게 이동하지만 $a$축으로는 거의 이동하지 않는 불균형한 상황이 발생한다.

### 수식

$$v_t = \beta \cdot v_{t-1} + (1 - \beta) \cdot g_t^2$$
$$\theta_t = \theta_{t-1} - \frac{\alpha}{\sqrt{v_t} + \epsilon} \cdot g_t$$

- $v_t$: 그래디언트 제곱의 이동 평균
- $\beta$: 감쇠율 (보통 0.9)
- $\epsilon$: 수치 안정성을 위한 작은 값 ($10^{-8}$)

### 작동 방식

1. $a$와 $b$에 대한 편미분값을 각각 제곱한다.
2. 이 제곱 값들을 누적한다. (지수 이동 평균 사용)
3. 현재의 각 편미분값을 누적된 값의 제곱근으로 나눈다.

### 핵심 원리

> **가파른 축으로는 조심스럽게, 완만한 축으로는 과감하게 이동**

이 방법의 장점은 복잡한 Loss 함수 지형에서 잘 드러난다.
Loss 함수가 얕고 가파른 부분과 깊고 완만한 부분을 동시에 가지고 있을 때:

1. **가파른 부분**: 작은 이동으로도 Loss 값이 크게 변하는 부분으로, 많이 이동하면 최저점을 지나칠 수 있기 때문에 조심스럽게 이동하여 급격한 변화를 방지한다.
2. **완만한 부분**: Loss의 변화가 크지 않은 부분으로, 더 많이 이동해도 안전하기 때문에 과감하게 이동하여 평평한 영역을 빠르게 탈출할 수 있게 한다.

이를 통해, RMSProp은 다양한 지형의 Loss 함수에서 효율적으로 최소점을 찾아갈 수 있게 된다.
또한, 각 축으로 이동한 양을 누적하므로 **덜 이동한 축으로는 더 크게, 많이 이동한 축으로는 더 작게** 이동하도록 조정한다. 이는 각 파라미터의 전체적인 변화 이력을 반영하여 학습의 안정성을 높이는 역할을 한다.

## Adam (Adaptive Moment Estimation)

**Momentum**과 **RMSProp**의 장점을 결합한 최적화 알고리즘

> 상세 수식과 알고리즘은 [[Adam_논문_요약]] 페이지 참조

### 핵심 아이디어

| 구성 요소 | 역할 | 기여 알고리즘 |
|----------|------|--------------|
| 1차 모멘트 ($m_t$) | 그래디언트의 이동 평균 (방향성) | Momentum |
| 2차 모멘트 ($v_t$) | 그래디언트 제곱의 이동 평균 (스케일 조정) | RMSProp |
| 편향 보정 | 초기 학습 안정화 | Adam 고유 |

### 기본 하이퍼파라미터

| 파라미터 | 기본값 | 역할 |
|---------|-------|------|
| $\alpha$ | 0.001 | 학습률 |
| $\beta_1$ | 0.9 | 1차 모멘트 감쇠율 |
| $\beta_2$ | 0.999 | 2차 모멘트 감쇠율 |
| $\epsilon$ | $10^{-8}$ | 수치 안정성 |

| 알고리즘 | 방향 누적 | 적응적 LR | 편향 보정 | 특징 |

| GD | X | X | X | 기본, 느림 |

## K-Fold Cross Validation

![[스크린샷 2026-01-20 오후 6.47.42.png]]

### 사용 목적

Training data가 부족해서 일부를 Validation data로 사용하기 곤란할 때 사용하는 데이터 검증 방법이다.

### 문제점

편향된 검증 데이터는 결과를 왜곡시킬 수 있다.

### 해결책

각기 다른 train, val data의 조합으로 K개 모델을 만든다.

### 절차

1. 데이터를 K개의 fold로 분할
2. 각 fold를 한 번씩 validation set으로 사용
3. K개의 서로 다른 데이터 조합을 만들고, 각 조합에 대해 Loss를 구한 후 평균을 낸다.
4. 이 **평균 Val-Loss**를 기준으로 하이퍼파라미터를 선정하면 편향 문제를 줄일 수 있다.

> 단, K배만큼의 추가 학습 시간이 소요된다.

### 하이퍼파라미터 선정 후

1. 선택된 Set으로 **전체 훈련 데이터**를 사용해 새로운 모델을 생성
2. 또는 교차검증으로 생성한 K개 모델을 **앙상블**하여 Majority Vote & Soft Voting으로 최종 예측
