## 실험 1: 타원형 2차 함수

### 손실 함수

$$f(x, y) = 0.1x^2 + 2y^2$$

- **특징**: x축은 완만하고 y축은 가파름
- **최소점**: (0, 0)
- **예상**: 지그재그 현상 발생 (특히 SGD)

### 결과 그래프

![[optimizer_comparison_quadratic.png]]

### 실험 결과

| 알고리즘 | 최종 위치 | 최종 Loss |
|---------|----------|-----------|
| SGD | (-0.53, 0.00) | 0.028141 |
| Momentum | (-0.02, -0.02) | 0.000521 |
| RMSProp | (+0.15, -0.18) | 0.064184 |
| **Adam** | (+0.01, +0.01) | **0.000375** |

### 분석

1. **SGD**
   - 심한 지그재그 현상
   - 100스텝 후에도 최저점에 도달하지 못함
   - y축으로는 빠르게 수렴하지만 x축 수렴이 매우 느림

2. **Momentum**
   - 지그재그 감소
   - 관성을 활용해 x축 방향으로도 효과적으로 이동
   - SGD 대비 약 50배 이상 낮은 Loss

3. **RMSProp**
   - 축별 적응적 학습률 적용
   - 초반 진동이 있지만 점차 안정화
   - 하이퍼파라미터에 민감

4. **Adam**
   - 가장 안정적인 수렴
   - Momentum의 방향성 + RMSProp의 적응적 학습률
   - 가장 낮은 최종 Loss 달성

## 실험 2: Beale 함수

### 손실 함수

$$f(x, y) = (1.5 - x + xy)^2 + (2.25 - x + xy^2)^2 + (2.625 - x + xy^3)^2$$

- **특징**: 비대칭적이고 복잡한 지형
- **최소점**: (3, 0.5)에서 f = 0
- **예상**: Local minimum에 갇히기 쉬움

### 결과 그래프

![[optimizer_comparison_beale.png]]

### 실험 결과

| 알고리즘 | 최종 위치 | 최종 Loss |
|---------|----------|-----------|
| SGD | (-1.86, +1.38) | 1.114628 |
| Momentum | (-1.49, +1.45) | 1.238791 |
| RMSProp | (-2.10, +1.34) | 1.057372 |
| Adam | (-1.51, +1.45) | 1.231699 |

### 분석

1. **공통점**: 모든 알고리즘이 전역 최소점 (3, 0.5)에 도달하지 못함
2. **원인**:
   - 시작점 (-2, 2)이 전역 최소점과 멀리 떨어져 있음
   - 복잡한 지형에서 local minimum에 갇힘
3. **해결책**:
   - 더 많은 스텝 수
   - Learning Rate 스케줄링
   - 다양한 시작점에서 시도 (Random Restart)

## 알고리즘별 구현 핵심

### SGD

```python
x_new = x - lr * dx
y_new = y - lr * dy
```

### Momentum

```python
v = gamma * v + lr * grad
theta = theta - v
```

- $\gamma$: 모멘텀 계수 (보통 0.9)
- 이전 속도의 90%를 유지하며 현재 그래디언트 반영

### RMSProp

```python
v = beta * v + (1 - beta) * grad**2
theta = theta - lr * grad / (sqrt(v) + eps)
```

- 그래디언트 제곱의 지수 이동 평균으로 나눔
- 가파른 축은 작게, 완만한 축은 크게 이동

### Adam

```python
m = beta1 * m + (1 - beta1) * grad          # 1차 모멘트
v = beta2 * v + (1 - beta2) * grad**2       # 2차 모멘트
m_hat = m / (1 - beta1**t)                   # 편향 보정
v_hat = v / (1 - beta2**t)                   # 편향 보정
theta = theta - lr * m_hat / (sqrt(v_hat) + eps)
```

- Momentum (1차 모멘트) + RMSProp (2차 모멘트) + 편향 보정

## 핵심 정리

| 특성 | SGD | Momentum | RMSProp | Adam |
|-----|-----|----------|---------|------|
| 지그재그 해결 | X | O | O | O |
| 적응적 학습률 | X | X | O | O |
| 편향 보정 | X | X | X | O |
| 구현 복잡도 | 낮음 | 중간 | 중간 | 높음 |
| 하이퍼파라미터 민감도 | 높음 | 중간 | 중간 | 낮음 |

### 실무 권장사항

1. **기본 선택**: Adam (대부분의 경우 좋은 성능)
2. **일반화 성능 중시**: SGD + Momentum + Learning Rate 스케줄링
3. **희소 그래디언트**: Adam 또는 RMSProp
4. **하이퍼파라미터 튜닝 여유 없음**: Adam 기본값 사용
