from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, GRU, Dense, Dropout

# 시퀀스 데이터 생성 (과거 N일)
def create_sequences(X, y, time_steps=10):
    Xs, ys = [], []
    for i in range(len(X) - time_steps):
        Xs.append(X[i:(i + time_steps)])
        ys.append(y[i + time_steps])
    return np.array(Xs), np.array(ys)

X_seq, y_seq = create_sequences(X_train, y_train, time_steps=10)

    Dense(1, activation='sigmoid')

model.compile(

# Transformer 기반 모델
def create_transformer_model(time_steps, n_features):
    inputs = keras.Input(shape=(time_steps, n_features))

    # Multi-head Attention
    attention_output = MultiHeadAttention(
        num_heads=4,
        key_dim=n_features

    # Add & Norm
    attention_output = LayerNormalization()(inputs + attention_output)

    # Feed Forward
    ffn = Dense(64, activation='relu')(attention_output)
    ffn = Dropout(0.3)(ffn)
    ffn = Dense(n_features)(ffn)

### 5.1 강화학습 (Reinforcement Learning)

**개념 전환**: 분류 문제 → 순차적 의사결정 문제

**개선 방법**:
```python
import gym
from stable_baselines3 import PPO, A2C

class TradingEnv(gym.Env):
    def __init__(self, df):
        super(TradingEnv, self).__init__()
        self.df = df
        self.current_step = 0
        self.position = 0  # -1(공매도), 0(관망), 1(매수)

        # Action: 0(매도), 1(보유), 2(매수)
        self.action_space = gym.spaces.Discrete(3)

        # Observation: 모든 특징
        self.observation_space = gym.spaces.Box(
            low=-np.inf,
            high=np.inf,
            shape=(n_features,)
        )

    def step(self, action):
        # 행동에 따른 보상 계산
        reward = self._calculate_reward(action)
        self.current_step += 1
        done = self.current_step >= len(self.df) - 1
        obs = self._get_observation()

        return obs, reward, done, {}

    def _calculate_reward(self, action):
        # 실제 수익률 기반 보상
        actual_return = self.df.iloc[self.current_step]['target_return']

        if action == 2:  # 매수
            return actual_return
        elif action == 0:  # 매도
            return -actual_return
        else:  # 보유
            return 0

    def reset(self):
        self.current_step = 0
        self.position = 0
        return self._get_observation()

    def _get_observation(self):
        return self.df.iloc[self.current_step][feature_cols].values

# 학습
env = TradingEnv(train_df)
model = PPO("MlpPolicy", env, verbose=1)
model.learn(total_timesteps=100000)

# 평가
test_env = TradingEnv(test_df)
obs = test_env.reset()
for _ in range(len(test_df)):
    action, _states = model.predict(obs)
    obs, reward, done, info = test_env.step(action)
    if done:
        break
```

**예상 효과**: 53-65% (수익 최적화 직접 학습)

## 중요한 마인드셋

### 1. 현실적 기대치
> "주가 예측은 세계에서 가장 어려운 문제 중 하나"

- 60% 이상: 매우 우수 (헤지펀드 수준)
- 55-60%: 우수 (실전 가능)
- 53-55%: 양호 (장기 수익 가능)
- 50-53%: 개선 필요
- **50% 미만: 랜덤보다 못함 (현재 상태)**

### 2. 과적합 주의
- Test Set 성능이 Train보다 높으면 의심
- 백테스팅으로 검증 필수
- Out-of-sample 테스트 (미래 데이터)

### 3. 거래 비용 고려
- 53% 정확도라도 수수료 0.3% × 2 = 0.6% 고려하면 실제 수익률 감소
- 높은 승률보다 Risk-Reward 비율 중요

### 4. 앙상블이 답
- "No Free Lunch Theorem": 만능 모델은 없음
- 다양한 모델의 조합이 가장 안정적
