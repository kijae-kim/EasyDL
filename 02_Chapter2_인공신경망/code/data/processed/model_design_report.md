## 1. 모델 개요

### 설계된 3가지 모델

#### 1) 선형 회귀 (Linear Regression)
- **목적**: Chapter 2 기본 개념 적용, 베이스라인
- **구조**: y = wx + b
- **파라미터**: 25개 (24 weights + 1 bias)
- **손실 함수**: MSE
- **예측 대상**: 다음날 수익률 (연속값)

#### 2) 로지스틱 회귀 (Logistic Regression)
- **목적**: 이진 분류 최적화
- **구조**: σ(wx + b), σ는 Sigmoid 함수
- **파라미터**: 25개
- **손실 함수**: Binary Cross-Entropy
- **예측 대상**: 다음날 등락 (0 or 1)

#### 3) MLP (Multi-Layer Perceptron)
- **목적**: 비선형 패턴 학습, 최고 성능
- **구조**: 24 → 32(ReLU) → 16(ReLU) → 1(Sigmoid)
- **파라미터**: 1,345개
- **정규화**: Dropout (0.3)
- **손실 함수**: Binary Cross-Entropy
- **Optimizer**: Adam (lr=0.001)
- **예측 대상**: 다음날 등락 (0 or 1)
