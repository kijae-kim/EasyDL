# Simple Kospi - KOSPI 등락 예측 모델

> Chapter 2 (인공신경망) 학습 내용을 실전 데이터로 직접 구현한 프로젝트

## 프로젝트 소개

KOSPI 지수와 KODEX200 ETF 데이터를 활용하여 다음날 주가 등락을 예측하는 머신러닝 프로젝트입니다.
교재의 YouTube 수익 예측 예제 대신, **금융 데이터에 관심이 있어 자발적으로 데이터를 수집하고 실습**했습니다.

## 기획 배경

Chapter 2에서 학습한 개념들을 실전에 적용하기 위해:
- **선형 회귀**: 기본 회귀 모델로 수익률 예측
- **로지스틱 회귀**: 이진 분류로 등락 방향 예측
- **MLP (다층 퍼셉트론)**: 비선형 패턴 학습으로 성능 개선 시도

교재 예제를 따라하는 대신, 실제 관심 분야(금융)의 데이터로 학습하면서 **데이터 수집부터 모델 평가까지 전 과정을 경험**했습니다.

## 주요 발견

### 1. 주가 예측의 어려움
- 최고 성능: **49.79%** (Logistic Regression)
- Random Baseline: **50.00%**
- **단순 기술적 지표만으로는 주가 예측이 거의 불가능**함을 확인

### 2. 모델별 특징
| 모델 | Test Accuracy | 특징 |
|------|---------------|------|
| 선형 회귀 | R² = -0.057 | 수익률 변동성을 설명하지 못함 |
| 로지스틱 회귀 | 49.79% | 가장 안정적, 해석 용이 |
| MLP | 47.33% | Recall 높지만 False Positive 많음 |

### 3. 인사이트
- 월요일 효과 발견: 월요일 상승 확률 **62.28%** (통계적으로 유의)
- 특징 중요도: `kospi_ma60`, `kospi_range_pct`, `kospi_return`이 가장 중요
- 과적합 없이 안정적으로 학습됨 (Train-Test 격차 10% 미만)

### 4. 교훈
> "이론적으로 완벽한 모델도 실전 데이터에서는 한계가 있다"

금융 시장의 불확실성과 무작위성으로 인해 기술적 지표만으로는 예측이 어려움을 체감했습니다.
더 나은 성능을 위해서는 뉴스 감성 분석, 거시경제 지표 등 추가 데이터가 필요합니다.

## 배운 점

### 1. 이론과 실전의 간극
> "교과서의 완벽한 모델도 실전에서는 50%를 넘기 어렵다"

- Chapter 2에서 배운 MLP, 로지스틱 회귀 등을 실제로 구현했지만 Random Baseline조차 넘지 못함
- **주가 예측의 본질적 어려움**: Random Walk 이론, 효율적 시장 가설의 현실성 체감
- 이론적 정확성과 실전 유용성은 별개임을 깨달음

### 2. 데이터가 모델보다 중요하다
> "Garbage In, Garbage Out"

- **좋은 데이터 > 좋은 모델**: 기술적 지표만으로는 한계 명확
- 특징 중요도 최고값이 0.0269 (거의 무작위 수준) → 신호 대 잡음비 매우 낮음
- 외부 변수(뉴스, 글로벌 시장, 거시경제) 없이는 근본적 개선 불가능
- **도메인 지식의 필수성**: 금융 시장 이해 없이는 좋은 특징 생성 불가

### 3. Baseline의 중요성
- Random Baseline (50%)과 비교하지 않았다면 49.79%가 좋은지 나쁜지 판단 불가
- **실전 기준 설정**: 53% 이상이면 수익 가능, 60% 이상이면 헤지펀드 수준
- 절대적 정확도보다 상대적 개선이 중요

### 4. 과적합과의 싸움
- Dropout (0.3), Early Stopping (patience=15)으로 일반화 성능 확보
- Train-Test 격차 10% 미만 유지 → 안정적 학습 확인
- **시계열 데이터 특성**: Shuffle 금지, 시간 순서 보존 필수

### 5. 평가 지표의 다면성
- **Accuracy만으론 부족**: Precision, Recall, F1, Confusion Matrix 종합 고려
- MLP가 Recall 83%로 높지만 Precision 낮아 False Positive 과다 → 실전 부적합
- 금융에서는 **Risk-Reward 비율**이 승률보다 중요

### 6. "실패"에서 배운 것이 더 많다
> "49.79%는 실패가 아니라 귀중한 학습 경험"

- 성공 사례만 보면 주가 예측이 쉬워 보이지만, 실패를 통해 본질적 어려움 이해
- 월요일 효과 발견 (62.28%) 등 데이터 분석 과정 자체가 학습
- 다음 프로젝트에서 무엇을 개선해야 하는지 명확한 방향성 획득

### 7. 점진적 개선의 중요성
- 한 번에 완벽한 모델을 만들 수 없음
- Stage별 파이프라인 구축 (수집→전처리→분석→설계→학습) 경험
- 각 단계의 리포트와 시각화로 진행 상황 추적

## 향후 발전 방안

현재 성능(49.79%)을 개선하기 위한 두 가지 주요 방향을 계획 중입니다.

### 방안 1: LSTM 시계열 모델 (⭐⭐⭐ 난이도)

**배경**: 현재 MLP는 시간 순서를 고려하지 못함. 주가는 본질적으로 시계열 데이터이므로 과거 패턴을 학습하는 RNN 계열 모델이 더 적합할 수 있음.

**구현 계획**:
```python
# 과거 10일 데이터를 시퀀스로 입력
시퀀스 생성: [t-10, t-9, ..., t-1] → t일 예측

모델 아키텍처:
- Bidirectional LSTM (64 units)
- Attention Layer (중요 시점 자동 포착)
- Dropout (0.3)
- Dense Layer (1, sigmoid)
```

**예상 효과**:
- 목표 정확도: **53-56%**
- 시간적 의존성 학습 가능
- 추세, 모멘텀 패턴 포착

**필요 학습**:
- Chapter 7: RNN, LSTM 이론
- Sequence-to-One 아키텍처
- Attention 메커니즘

**예상 기간**: 2-3주

---

### 방안 2: 외부 데이터 통합 (⭐⭐⭐ 난이도)

**배경**: 현재는 KOSPI/KODEX 기술적 지표만 사용. 주가는 글로벌 시장, 환율, 정책 등 외부 요인에 크게 영향받음.

**구현 계획**:

#### 2.1 글로벌 시장 데이터
```python
- S&P500 (전날 미국 시장 영향)
- VIX (공포지수, 변동성)
- 중국 상해종합지수
- 일본 닛케이225
```

#### 2.2 거시경제 지표
```python
- USD/KRW 환율 (원화 강세/약세)
- 국고채 10년물 금리
- Yield Curve (10년 - 3년 스프레드)
- 원자재 가격 (유가, 금)
```

#### 2.3 특징 엔지니어링 강화
```python
- 요일 효과 활용 (월요일 62.28% 상승)
- MACD, Bollinger Bands 추가
- 시차 특징 (lag 1, 3, 5일)
- 거래량-가격 상호작용 특징
```

**예상 효과**:
- 목표 정확도: **53-58%**
- 외부 충격 반영 가능
- 다양한 신호 통합

**필요 작업**:
- 다중 소스 데이터 수집 자동화
- 시간대 동기화 (미국 전날 → 한국 당일)
- 결측치 처리 전략

**예상 기간**: 3-4주

---

### 통합 방안: LSTM + 외부 데이터 (⭐⭐⭐⭐⭐)

두 방안을 결합하면 시너지 효과 기대:
- LSTM으로 시계열 패턴 학습
- 외부 데이터로 추가 신호 확보
- **목표 정확도: 55-60%**

**궁극적 목표**: 실전 거래 가능한 모델 (53% 이상)
