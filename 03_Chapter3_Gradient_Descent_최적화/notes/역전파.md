
### 학습목표
비선형성의 중요성에 초점을 맞춰 비선형 액티베이션이 왜 딥러닝에 필수적인지 알아보자

## MLP, 행렬과 벡터로 표현하기

**MLP의 기본 연산:**
- 가중치 곱하기 → 편향 더하기 → 활성화 함수 적용
- 개념은 단순하지만, 수식으로 표현하면 노드/층 수에 따라 복잡해짐

**예시: 입력 2개 → 히든 레이어(3노드) → 출력층**

각 히든 노드의 출력:
1. $f_1(x_1w_1 + x_2w_2 + b_1)$
2. $f_1(x_1w_3 + x_2w_4 + b_2)$
3. $f_1(x_1w_5 + x_2w_6 + b_3)$

**문제점:** 출력층까지 전개하려면 위 세 값에 또 가중치, 편향, 활성화를 적용해야 함
→ 층이 깊고 노드가 많으면 수식이 매우 복잡해짐

**해결:** 행렬과 벡터를 이용하면 간단하게 표현 가능

$$
\begin{pmatrix}
x_1 & x_2
\end{pmatrix}
\begin{pmatrix}
w_1 & w_3 & w_5 \\
w_2 & w_4 & w_6
\end{pmatrix} +
\begin{pmatrix} b_1 & b_2 & b_3 \end{pmatrix}
$$
입력 벡터를 x, 웨이트 행렬을 W1, 바이어스 벡터를 b1으로 표기하여 표현 $f1(xW1 + b1)$


## 비선형 액티베이션의 중요성

**핵심 질문:** 왜 비선형 함수를 사용해야 할까?

### 선형 액티베이션의 한계

> *복잡도: 함수가 표현하는 입력-출력 간 관계의 복잡한 정도*

**선형만 사용하면?** → 아무리 깊어도 FC 레이어 1층과 동일한 복잡도

**수식으로 증명:**
- 선형 액티베이션: $f(x) = x$ (입력을 그대로 출력)
- 1층: $f_1(xW_1 + b_1) = xW_1 + b_1$
- 2층: $f_2(f_1(xW_1+b_1)W_2 + b_2) = xW_1W_2 + b_1W_2 + b_2$

**치환하면:**
- $W = W_1W_2$, $b = b_1W_2 + b_2$로 놓으면
- $xW + b$ → 단일 층과 동일한 수식!

**결론:**
- 100층이어도 1층과 같은 복잡도
- 이유: **선형 함수의 합성 = 선형 함수**
- 한계: 입출력 간 선형 관계만 표현 가능 → 복잡한 패턴 학습 불가

### 비선형 액티베이션의 효과

- 입력-출력 간 **비선형 관계** 표현 가능
- 층이 깊어질수록 **더 복잡한 함수** 표현 가능

### 그렇다면 선형 액티베이션은 불필요한가?

**아니다!** 회귀 문제의 출력층에서 필요
- 출력값 범위가 제한되면 안 되는 경우
- $f(x) = x$ (항등 함수) 사용

> **$x^3$ 같은 함수의 문제점:**
> - **그라디언트 폭발**: $\frac{d}{dx}x^3 = 3x^2$로, 입력값이 크면 그라디언트가 급격히 커짐
> - **그라디언트 소실**: 입력값이 0에 가까우면 그라디언트도 0에 가까워짐
> - **출력 범위 무제한**: 값이 무한히 커질 수 있어 수치적 불안정성 유발
> - 따라서 출력층에서는 단순히 $f(x) = x$ (항등 함수)를 사용하는 것이 안정적


## 순전파 (Forward Propagation)

> 입력 데이터가 네트워크를 통과하며 출력을 계산하는 과정

**계산 단계:**

| 단계 | 연산 | 수식 |
|------|------|------|
| 1. 입력층 → 히든층 | 선형변환 + 활성화 | $z_1 = xW_1 + b_1$, $h = f(z_1)$ |
| 2. 히든층 → 출력층 | 선형변환 + 활성화 | $z_2 = hW_2 + b_2$, $\hat{y} = g(z_2)$ |
| 3. 손실 계산 | 예측값과 실제값 비교 | $L = \text{Loss}(\hat{y}, y)$ |

- $f$: 히든층 활성화 함수
- $g$: 출력층 활성화 함수

> **순전파의 핵심**: 각 층에서 계산된 중간값($z_1$, $h$, $z_2$)을 저장해두어야 역전파에서 사용할 수 있다.

## 역전파 (Back Propagation)

> 각 파라미터에 대한 Loss의 편미분을 **효율적으로** 계산하는 핵심 알고리즘

**특징:**
- **방향**: 출력층 → 입력층 (역방향)
- **핵심 원리**: 연쇄법칙(Chain Rule) 적용
- **효율성**: 중간 계산 결과를 재사용

**다중 경로 규칙:**
- 여러 변수를 통해 영향받는 함수의 편미분 계산 시
- 모든 경로에 대한 편미분값을 **더해야** 함
- 이 패턴은 **기울기 소실 문제** 이해의 핵심

### 역전파 수식 예시 (2층 네트워크)

간단한 2층 네트워크를 예로 들어보자:
- 입력: $x$
- 히든층: $h = f(xW_1 + b_1)$
- 출력층: $\hat{y} = h W_2 + b_2$
- 손실함수: $L = \frac{1}{2}(\hat{y} - y)^2$

**연쇄법칙 적용:**

1. **출력층 가중치 $W_2$에 대한 그라디언트:**
$$\frac{\partial L}{\partial W_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W_2} = (\hat{y} - y) \cdot h$$

2. **히든층 가중치 $W_1$에 대한 그라디언트:**
$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial h} \cdot \frac{\partial h}{\partial W_1} = (\hat{y} - y) \cdot W_2 \cdot f'(xW_1 + b_1) \cdot x$$

> **핵심 포인트**: $\frac{\partial L}{\partial \hat{y}} = (\hat{y} - y)$는 한 번만 계산하고, 이후 역방향으로 전파하면서 재사용한다. 이것이 역전파의 효율성의 핵심이다.

### 계산 그래프 (Computational Graph)

역전파를 직관적으로 이해하는 방법은 **계산 그래프**를 그리는 것이다.

```
[순전파 방향 →]

  x ──→ [×W₁] ──→ [+b₁] ──→ [f] ──→ h ──→ [×W₂] ──→ [+b₂] ──→ ŷ ──→ [Loss] ──→ L
                              ↑                                          │
                              │          [← 역전파 방향]                  │
                              └──────────────────────────────────────────┘
```

**계산 그래프의 장점:**
- 각 노드에서 **국소적 미분**만 계산하면 됨
- 연쇄법칙에 따라 역방향으로 미분값을 곱해가며 전파
- 분기(branch)가 있으면 그라디언트를 **더함** (다중 경로 규칙)

**예시 - 덧셈 노드와 곱셈 노드:**
- 덧셈 노드 $z = x + y$: 역전파 시 그라디언트를 그대로 전달 ($\frac{\partial z}{\partial x} = 1$)
- 곱셈 노드 $z = x \times y$: 역전파 시 상대방 값을 곱해서 전달 ($\frac{\partial z}{\partial x} = y$)

## 기울기 소실 문제 (Vanishing Gradient Problem)

> 역전파 시 그라디언트가 층을 거슬러 올라갈 때 **활성화 함수의 미분값**이 계속 곱해짐

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot W_2 \cdot \underbrace{f'(z_1)}_{\text{활성화 함수 미분}} \cdot x$$

### Sigmoid의 문제

| 항목 | 내용 |
|------|------|
| 함수 | $\sigma(x) = \frac{1}{1+e^{-x}}$ |
| 미분 | $\sigma'(x) = \sigma(x)(1-\sigma(x))$ |
| 미분 최댓값 | **0.25** ($x=0$일 때) |
| 포화 영역 | 입력이 크거나 작으면 미분값 → 0 |

**10층 네트워크 예시:**

$$0.25^{10} = 0.00000095$$

→ 그라디언트가 거의 사라짐 → 앞쪽 층의 가중치가 업데이트되지 않음

### 해결 방법

| 방법 | 설명 |
|------|------|
| **ReLU** | $f(x) = \max(0, x)$, 양수 영역에서 미분값이 항상 1 |
| **He 초기화** | ReLU에 맞춘 가중치 초기화 방법 |
| **Batch Normalization** | 각 층의 입력을 정규화하여 포화 영역 방지 |
| **Residual Connection** | 그라디언트가 직접 전달되는 지름길 제공 |
