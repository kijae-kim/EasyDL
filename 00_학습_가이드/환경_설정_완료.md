## 🔧 문제 해결

### 가상환경이 활성화되지 않아요

```bash
# 권한 확인
ls -la EasyDL/bin/activate

# 실행 권한 부여
chmod +x EasyDL/bin/activate

# 다시 활성화
source EasyDL/bin/activate
```

### TensorFlow 임포트 오류

```bash
# 가상환경에서 재설치
pip uninstall tensorflow
pip install tensorflow>=2.13.0
```

### Obsidian이 실행되지 않아요

```bash
# 터미널에서 수동 실행
open -a Obsidian

# 또는 Finder에서
# /Applications/Obsidian.app 더블클릭
```
