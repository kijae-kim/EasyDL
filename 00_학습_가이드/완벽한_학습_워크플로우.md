## 🌅 학습 시작 전 준비 (1회만)

```bash
cd /Users/gimgijae/Desktop/Paper/EasyDL
./scripts/setup_github.sh
```

프롬프트에 따라 GitHub 저장소 URL 입력

### 2. Obsidian Vault 연결

1. Obsidian 실행
2. "Open folder as vault" 선택
3. `/Users/gimgijae/Desktop/Paper/EasyDL` 선택
4. "Trust author" 선택

### 3. Obsidian Git 플러그인 설치

1. `Settings (⚙️)` → `Community plugins` → `Browse`
2. "Git" 검색 → **"Obsidian Git"** 설치
3. 설정:
   - Vault backup interval: `10` (10분마다 자동 커밋)
   - Auto push: `ON`
   - Commit message: `{{date}} 학습 기록 자동 저장`

### 📚 학습 중 (30분 - 2시간)

#### Obsidian에서 (이론)

1. **새 노트 생성**
   - `Cmd + N`
   - 파일명: `Chapter번호/notes/강의제목.md`
   - 예: `01_Chapter1_딥러닝_시작/notes/01_퍼셉트론.md`

2. **템플릿 삽입**
   - `Cmd + P` → "Insert template"
   - "학습_노트_템플릿" 선택

3. **학습 목표 작성**
   ```markdown
   ## 📌 학습 목표
   - [ ] 퍼셉트론의 개념 이해
   - [ ] 단순 퍼셉트론 구조 파악
   - [ ] Python으로 구현
   ```

4. **강의 시청하며 정리**
   - 핵심 개념을 마크다운으로 정리
   - 수식은 LaTeX로 작성: `$$ 수식 $$`
   - 중요한 부분은 **볼드** 처리

5. **이해 안 되는 부분 표시**
   ```markdown
   ❓ **질문**: 왜 XOR 문제를 못 푸는가?
   ```

#### VSCode + Claude Code에서 (실습)

1. **코드 파일 생성**
   ```bash
   # 터미널에서
   touch 01_Chapter1_딥러닝_시작/code/perceptron.py
   ```

2. **Claude에게 질문하며 구현**

   예시 대화:
   ```
   나: 퍼셉트론을 Python으로 구현하고 싶어.
       NumPy를 사용해서 클래스로 만들어줘.

   Claude: [코드 제공]

   나: 이 코드에서 활성화 함수 부분을 설명해줘.

   Claude: [설명]

   나: AND 게이트로 테스트해볼게. 어떻게 하지?

   Claude: [테스트 코드 제공]
   ```

3. **코드 실행 및 테스트**
   ```bash
   python 01_Chapter1_딥러닝_시작/code/perceptron.py
   ```

4. **결과 스크린샷**
   - `Cmd + Shift + 4`로 스크린샷
   - `assets/` 폴더에 저장

#### Obsidian으로 돌아와서 (정리)

1. **Claude와의 Q&A 추가**
   ```markdown
   ## 🤔 Claude와의 Q&A

   ### Q1: 퍼셉트론의 활성화 함수는 왜 계단 함수인가?
   **A1**: [Claude의 답변 복사]
   ```

2. **코드 첨부**
   ```markdown
   ## 💻 코드 구현

   **파일**: `code/perceptron.py`

   ```python
   # 코드 붙여넣기
   ```
   ```

3. **실행 결과 첨부**
   ```markdown
   ## 📊 실험 결과

   ![실행 결과](../assets/perceptron_result.png)

   AND 게이트 테스트 결과:
   - 입력 [0, 0]: 출력 0 ✅
   - 입력 [0, 1]: 출력 0 ✅
   - 입력 [1, 0]: 출력 0 ✅
   - 입력 [1, 1]: 출력 1 ✅
   ```

4. **핵심 정리**
   ```markdown
   ## 💡 핵심 정리

   1. **퍼셉트론**: 가장 단순한 형태의 인공 신경망
   2. **학습 규칙**: Δw = η(y - ŷ)x
   3. **한계**: 선형 분리 가능한 문제만 해결 가능
   4. **XOR 문제**: 단층 퍼셉트론으로 불가능
   ```

5. **상태 업데이트**
   ```markdown
   ---
   status: ✅ 완료
   ---
   ```

### 효율적인 학습

1. **뽀모도로 기법**
   - 25분 집중 → 5분 휴식

   - 학습 당일: 1회
   - 3일 후: 1회
   - 1주일 후: 1회
   - 1달 후: 1회

### Git 관리

1. **의미 있는 커밋**
   - 자동 커밋 외에 중요한 마일스톤은 수동 커밋
   - 예: "Chapter 1 완료", "프로젝트 완성"

2. **브랜치 활용** (고급)
   ```bash
   # 실험용 브랜치
   git checkout -b experiment/new-idea

   # 실험 성공 시 main에 병합
   git checkout main
   git merge experiment/new-idea
   ```
