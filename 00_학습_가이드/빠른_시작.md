## ✅ Step 1: Obsidian Vault 연결 (1분)

Obsidian이 이미 실행되어 있습니다.

1. **"Open folder as vault"** 클릭
2. 폴더 선택:
   ```
   /Users/gimgijae/Desktop/Paper/EasyDL
   ```
3. **"Trust author"** 선택

---

## ✅ Step 2: GitHub 저장소 연결 (2분)

### 터미널에서:

```bash
cd /Users/gimgijae/Desktop/Paper/EasyDL
./scripts/setup_github.sh
```

프롬프트에 따라:
1. GitHub 저장소 URL 입력
2. 푸시 여부 선택 (Y)

### GitHub 저장소가 없다면?

1. https://github.com/new 접속
2. 저장소 이름: `EasyDL`
3. Public 선택
4. `Create repository` 클릭
5. 생성된 URL 복사 (예: `https://github.com/kijae-kim/EasyDL.git`)

---

## ✅ Step 3: Obsidian Git 플러그인 설치 (2분)

Obsidian에서:

1. `Settings (⚙️)` → `Community plugins` → `Browse`
2. 검색: **"Git"**
3. **"Obsidian Git"** 설치
4. `Enable` 클릭
5. 설정:
   ```
   Vault backup interval: 10
   Auto push: ON
   Commit message: {{date}} 학습 기록 자동 저장
   ```

## 📝 첫 학습 노트 작성

### Obsidian에서:

1. `Cmd + N` (새 노트)
2. 저장 위치: `01_Chapter1_딥러닝_시작/notes/01_퍼셉트론.md`
3. `Cmd + P` → "Insert template" → "학습_노트_템플릿"
4. 정보 입력:
   ```yaml
   chapter: "Chapter 1"
   topic: "퍼셉트론"
   lecture_url: "https://youtu.be/13wbFxjz0d4"
   ```
