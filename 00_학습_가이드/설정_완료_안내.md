### 2. Obsidian Git 플러그인 설치 (2분)

Vault가 연결되면 Obsidian에서:

1. `Settings (⚙️)` 클릭 (왼쪽 하단)
2. `Community plugins` 클릭
3. **"Turn on community plugins"** 클릭 (처음이면)
4. `Browse` 버튼 클릭
5. 검색창에 **"Git"** 입력
6. **"Obsidian Git"** by Vinzent 찾기
7. `Install` 클릭
8. `Enable` 클릭

#### 플러그인 설정:

`Settings` → `Community plugins` → `Obsidian Git` (톱니바퀴 아이콘):

```
✅ Vault backup interval (minutes): 10
✅ Auto push: ON
✅ Commit message: {{date}} 학습 기록 자동 저장
✅ Pull updates on startup: ON
```

저장하고 닫기!

### 3. 첫 학습 노트 작성 (지금 바로!)

#### Obsidian에서:

1. **새 노트 생성**
   - `Cmd + N` (Mac) 또는 `Ctrl + N` (Windows)

2. **파일 저장 위치**
   - 폴더: `01_Chapter1_딥러닝_시작/notes/`
   - 파일명: `01_퍼셉트론.md`

3. **템플릿 삽입**
   - `Cmd/Ctrl + P` (명령 팔레트)
   - "Insert template" 입력
   - "학습_노트_템플릿" 선택

4. **정보 입력**
   ```yaml
   ---

   topic: "퍼셉트론"
   lecture_url: "https://youtu.be/13wbFxjz0d4"

   ```
